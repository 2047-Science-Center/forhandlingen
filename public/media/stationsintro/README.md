# Stationsintro (hype-klipp)

Spelas av station-kit/entre (StationIntro.vue) när gruppen tryckt på "Ställ er på rätt sida", före rollvalet.

- **Fil:** `<station>.mp4` här: `forhandlingen.mp4` · `manniskotestet.mp4` · `undersokningen.mp4` (· `reaktorkarnan.mp4`)
- **Format:** MP4, H.264 (yuv420p) + AAC-ljud, 1920×1080, 25 eller 30 fps, **5–6 s**, `+faststart`.
  16:9 (visas `object-fit: contain` på svart). Ljudet spelas om stationens ljud är på, annars tyst.
- Saknas filen hoppas introt över. Ett tryck hoppar över det. Max 15 s (säkerhetsspärr).
